Modellar
--------

User:
  - id
  - fullName (string)
  - email (unique)
  - passwordHash (string)
  - createdAt

Task:
  - id
  - userId (ref: User)
  - title (string)
  - description (string, optional)
  - status (TODO | IN_PROGRESS | DONE)
  - priority (LOW | MEDIUM | HIGH)
  - dueDate (date, optional)
  - createdAt
  - updatedAt

Frontend - Sahifalar
---------------------

1. Register sahifasi - /register

To'liq ism, email va parol kiritish maydonlari bo'lsin.
Pastda "Akkauntingiz bormi? Kirish" havolasi bo'lsin.

2. Login sahifasi - /login

Email va parol kiritish maydonlari bo'lsin.
Pastda "Akkauntingiz yo'qmi? Ro'yxatdan o'ting" havolasi bo'lsin.

3. Dashboard sahifasi - /dashboard

Yuqorida Navbar bo'lsin: foydalanuvchi ismi va chiqish tugmasi.

Vazifalar 3 ta ustunda joylashsin:
  TODO         IN_PROGRESS        DONE
  --------     -----------        ----
  Vazifa 1     Vazifa 3           Vazifa 5
  Vazifa 2     Vazifa 4

Har bir vazifa kartochkasida quyidagilar bo'lsin:
  - Sarlavha
  - Muhimlik darajasi (rangli)
  - Muddat (agar berilgan bo'lsa)
  - Tahrirlash tugmasi
  - O'chirish tugmasi
  - Status o'zgartirish tugmasi

Yangi vazifa qo'shish tugmasi sahifa yuqorisida bo'lsin.

4. Task Modal

Vazifa yaratish va tahrirlash bitta modal orqali ishlashi kerak.
Modal ichida:
  - Sarlavha (majburiy)
  - Tavsif (ixtiyoriy)
  - Muhimlik darajasi: LOW | MEDIUM | HIGH
  - Muddat (ixtiyoriy)
  - Saqlash va Bekor qilish tugmalari


Frontend Talablari
------------------

Himoya:
  - Login qilmagan foydalanuvchi dashboard ga kira olmasin - PrivateRoute bilan himoyalang
  - Login yoki Register sahifasiga kirgan foydalanuvchi agar login bo'lgan bo'lsa dashboard ga yo'naltirilsin
  - Token localStorage da saqlansin

Dashboard:
  - O'chirishda foydalanuvchidan tasdiqlash so'ralsin
  - Status o'zgartirish kartochka ichidagi tugma orqali ishlashi kerak
  - Yangi vazifa yaratish va tahrirlash bitta modal orqali ishlashi kerak

Tailwind ranglari:
  Muhimlik darajasi:
    HIGH   - qizil rang
    MEDIUM - sariq rang
    LOW    - yashil rang

  Ustun ranglari:
    TODO        - kulrang
    IN_PROGRESS - ko'k rang
    DONE        - yashil rang

axios.js faylida:
  - Har bir so'rovga token avtomatik qo'shilsin
  - Token muddati o'tsa refresh qilsin
  - Refresh ham ishlamasa login sahifasiga yuborsin
